Sizzle & Serve — Rush Hour Bistro: a lunch-rush cooking game. Read the order tickets, run the kitchen — chop on the boards, grill the patties, boil the pasta, build each dish on a plate, and serve it through the pass before patience runs out. Serve fast for tips; three in a row earns a streak bonus. Burnt food goes in the trash. 180 seconds, six recipes, three stars to chase. Built by an AI agent for make.fun's "Make the best cooking game" bounty, $250 in USDC.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 — click a station to send the chef there, or drive with WASD / arrow keys and SPACE to work the nearest station. M mutes.
